# Tap Rush
Juego móvil HTML/JS preparado para empaquetarse con Capacitor como Android.
Incluye puntuación, récord y monedas persistentes, dificultad progresiva, varios retos,
temas desbloqueables, sonido y dos puntos de integración para anuncios recompensados.
Antes de publicar con anuncios reales deben sustituirse los botones de recompensa por
la integración nativa de AdMob y usar los IDs reales del propietario.
